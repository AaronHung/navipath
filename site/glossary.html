架構圖每個 block 在說什麼

被老師/reviewer 問時可直接查，也可當 rebuttal 彈藥。持續添增。來源：docs/wiki/06_glossary.md。顏色對應架構圖：藍＝frozen backbone、綠＝CNL（Agent）、紫＝CL 記憶、灰＝future。

一、輸入與 backbone（藍）
Whole-Slide Image / Patch Pool

病理切片是 gigapixel 巨圖，切成上千個小方塊（patch）。這堆 patch ＝ patch pool。

Feature Interface CONCH / Pathology FM

「翻譯官」：用預訓練模型把每個 patch 變成 512 維向量，讓 backbone 與 agent 都看得懂，不直接吃像素。

Frozen Diagnostic Backbone

真正下診斷的模型（本次＝QPMIL-VL）。Frozen＝完全不訓練，只借它看 patch、出診斷。凍結是故意的→贏了才能歸因是「我們的 navigation」。

Slide-level Prediction

backbone 看完我們挑的 patch 後，給整張片子的診斷（癌種／分數）。

二、CNL（綠）＝ Agent，怎麼看
Observation State 觀察狀態

單張片子內的「當前筆記／短期記憶」：看過哪些 patch、像哪一類、backbone 多有把握、看了幾%。讓「下一步看哪」取決於已看到的→序列決策。

Navigation Policy 導覽策略

決策大腦：依 Observation State 幫每個未看 patch 打分，決定哪些值得看。

Budgeted Sequential Observation

Budgeted＝只准看 K 個 patch；Sequential＝分多輪看。流程：看一點→更新 state→再決定看哪→再看，直到用完 K。

Navigation Trace 導覽軌跡

agent 依序看了哪些地方的紀錄＝可解釋性產出；也是跟 QPMIL「一次吃全部」最大的差異。

三、CL 記憶（紫）＝ 怎麼不忘
Context / Task Gate 情境/任務閘門

開關／路由器：看到新片子，決定這張要用 NSM 裡哪一套技能（像把病例分流到對的專科）。

oracle 理想答案來源

ML 裡 oracle＝「直接給正確答案的理想來源」，一種合理作弊，用來量最好情況（上界）。oracle gate＝我們直接告訴 Gate 這張是哪個癌種→一定挑對技能。先拿掉「分流分錯」這變數，純驗證記憶+技能有沒有用。未來 task-free＝不給答案、模型自己推。

Navigation Skill Memory NSM

跨任務長期記憶：學完一個癌種，把「看這種癌該怎麼看」的技能存進「技能銀行」。CL 的記憶體在此→忘記與恢復都發生在這裡。

CL Update 持續學習更新

管理 NSM 的規則：學新任務時新增技能、凍結舊技能、（未來）合併/重播，避免學新洗掉舊。

分工一句話：Observation State＝單片內短期記憶（Agent）；NSM＝跨任務長期記憶（CL）；Gate＝決定這張片子拿哪套技能。
四、Future work（灰，虛線框，這次不做）
Feature Replay Memory 特徵重播記憶

未來存「代表性 patch 特徵向量」，學新任務時拿出來複習防遺忘。存特徵，跟 NSM 存「技能」不同。

Reward / Preference Model

未來有醫師資料時，評分「agent 看的順序好不好、有沒有看對地方」。

North Star signals

長期願景訊號：醫師瀏覽軌跡、放大/移動動作、人類回饋（RLHF）。現在沒資料→列未來。

task-free Gate

未來版的 Gate：不靠 oracle，模型自己從片子推測任務是哪一類。

五、底部標籤 與 介面契約
Continual task stream t = 1 … T

任務一個接一個來（癌種 1→2→3…），不是一次全給。＝持續學習的舞台：學後面會不會忘前面。

Phase-0 instance: QPMIL-VL + CONCH

提醒：整套是通用框架，QPMIL 只是這次插進 backbone 槽的一個例子，非主角。

encode / predict / task_query

對 backbone 的介面契約：encode(WSI)→每 patch 特徵；predict(subset)→只給一部分 patch 也能出診斷；task_query→（選用）推測任務。詳見 架構頁 §06。
