## 0. 一句話開場（15 秒）
> 「我們把既有的 WSI navigation agent，升級成一層**通用、可持續學習的『看哪裡』模組（Continual Navigation Layer）**，跑出一個 Phase-0 pilot：navigation 會遺忘、我們能修復，且贏過 zero-shot baseline。」

---

## 1. 問題（45 秒）· 開 `architecture.html` Fig.Problem
- WSI 是 gigapixel、幾千個 patch；實務只能在**有限觀察預算**內決定「看哪些 patch」＝一個 navigation policy。
- 近期工作（ZeroSlide）顯示「**分類**」用 frozen 病理 VLM 可 zero-shot、天生不忘。
- **但只要要做有預算、會主動選 patch 的 agent，就需要一個可訓練的 navigator——它一旦連續學多種癌症就會遺忘。** 這條「navigation 也需要 CL」的軸，過去沒人立。

## 2. 架構（60 秒）· 開 `architecture.html` Fig.1 總圖
- 凍結診斷 backbone（CONCH+QPMIL，只是一個 instance，可換）。
- 外掛 **CNL**，兩條正交軸：
  - **Agent（怎麼看）**：Observation State + budgeted sequential observation，輸出可稽核 Navigation Trace。
  - **CL（怎麼不忘）**：Navigation Skill Memory（NSM）+ Context Gate。
- **唯一訓練的**是一個 ~533KB 的小 policy（router）；backbone 全程凍結 → 任何效果只能歸因於我們這層。

## 3. 方法一句話（30 秒）
- router 用**弱監督**（只有 slide label）學會把「判別區」打高分、選出關鍵 K 個 patch。
- **NSM ＝ 每任務存一份 router**（坦白：這是 parameter-isolation **上界**，用來框出問題大小，不是最終方法）。
- 對照：**zero-shot navigator**（不訓練、用 FM 文字相似度選），檢驗「zero-shot navigation 夠不夠」。

## 4. 結果（90 秒）· 開 `board.html` D 區（表＋兩張圖）
reverse、3-fold、budget=64：

| 指標 | continual+NSM（我們） | naive（會忘） | zero-shot |
|---|---|---|---|
| mACC | **0.935** | 0.595 | 0.858 |
| Forgetting | **0** | 0.454 | 0 |

- 最舊任務 esca@64：**我們 0.911 vs naive 0.333**（修復 +0.58）。
- **三層故事**：naive 嚴重遺忘（問題真）→ NSM 完全修復（可解）→ zero-shot 很強但仍輸我們，且贏過 naive（continual navigation learning 再加值 +0.077）。
- 只看 ~1~2% patch 就追平看全部（0.911 vs 0.867）。

## 5. 誠實邊界（30 秒）
- 多步（sequential）這版**還沒贏單步**：policy 分數尚未依賴已看內容（靜態），是設計增量、非 bug。
- 目前 reverse 3-fold；paper-order 對稱、EWC baseline 待補。
- gate 用 oracle（上界假設）；task-free 是 future。

## 6. 後續計畫（45 秒）· 開 `architecture.html` Fig.Roadmap
- **7/20 目標**：把昂貴的 NSM 換成**便宜記憶**（prompt 或 LoRA 擇一），逼近上界；多步路線 A（推論期自適應，Mac 可做）。
- 之後：task-free gate → RL 多步 → move/zoom → 醫師軌跡/RLHF → select-before-encode（真正省算力，呼應 RLogist/Cordonnier）。
